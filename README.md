# Library-Management-APP
## Library App – Figma Project
### Project Overview
The Library App is a mobile application designed in Figma to help users search, borrow, and read books easily. It provides a simple and user-friendly digital library experience.

### Objective
The main objective is to make book searching and reading simple and convenient. The app helps users access books easily, organize their reading, and enjoy a better digital library experience.

###  Features
- Search books easily.
- Browse different book categories.
- View book details and ratings.
- Borrow and save favourite books.
- Read books and track progress.
- Manage user profile.

###  Design Highlights
- Clean and modern UI design.
- Blue and white colour combination.
- Attractive book cover images.
- Simple navigation and readable fonts.
- Low-fidelity and high-fidelity designs.
